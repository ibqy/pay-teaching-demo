# 支付对接核心知识点

## 支付流程

```
用户 → 商户下单 → 获取支付参数 → 用户支付 → 三方异步通知 → 更新订单
                                                              → 用户查询确认
                                                              → 退款（维权/取消）
```

## 标准对接步骤（支付宝、微信通用）

| 步骤 | 说明 | 关键点 |
|------|------|--------|
| 1. 下单 | 调用支付 SDK 获取支付参数 | 生成唯一商户订单号 outTradeNo |
| 2. 返回 | 返回二维码/H5链接/JS参数 | 不同展示方式差大 |
| 3. 用户支付 | 用户扫码/跳转/APP内完成支付 | 支付宝/微信处理 |
| 4. 异步通知 | 三方 POST 到商户 notifyUrl | **验签！幂等！** |
| 5. 查询确认 | 主动调用查询接口确认 | 回调可能丢失，需定时对账 |
| 6. 退款 | 申请退款到用户账户 | 全额 / 部分退款 |

## 核心术语

| 术语 | 说明 | 示例 |
|------|------|------|
| **outTradeNo** | 商户订单号（自己生成，全局唯一） | 20260912143012000001 |
| **tradeNo** | 三方流水号（支付成功返回） | 2026091222001481234567 |
| **签名** | 请求/响应防篡改 | RSA2 签名 + 验签 |
| **异步通知** | 支付成功后的回调 | 必须验签，返回 "success" |
| **幂等性** | 同笔回调处理多次 | 用 outTradeNo 去重 |
| **单位转换** | 支付宝用"元"，微信用"分" | 1 元 = 100 分 |
| **退款** | 全额或部分退款 | 不能超过原支付金额 |

## 支付宝 vs 微信差异

| 维度 | 支付宝 | 微信支付 |
|------|--------|----------|
| SDK | alipay-sdk-java | wechatpay-java（API v3） |
| 协议 | JSON 格式 | RESTful JSON |
| 签名算法 | RSA2 | RSA-SHA256 |
| 金额单位 | 元（BigDecimal） | 分（Integer） |
| 通知格式 | URL 参数 | 加密 JSON |
| 验签方式 | rsaCheckV1 | WechatPay-Signature header |
| 扫码支付 | trade.precreate（返回二维码链接） | Native（code_url） |
| 手机网页 | trade.wap.pay | H5（h5_url）
